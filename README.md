# Sistema de entrega de Pedidos CITY LINK.

Aplicación en JAVA para administrar Clientes, Pedidos, Repartidores y sus vehiculos.

Integrantes:
Fernández Valentina Sofia.

## Requerimientos Min.
Java Development Kit(JDK) 17.

## Para compilar
En terminal, en la raiz del proyecto ejecute:
```console
javac -d bin src/app/*.java src/exceptions/*java src/models/*.java
```
## Para ejecutar
```console
java -cp bin app.Main
```
